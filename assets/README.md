# Assets

Put optional images for the project here, for example:

- `dashboard.png` - a screenshot of the dashboard for the main README
- `languages.png` - a screenshot of the language analysis tab
- `logo.png` - a project logo, if you create one

The application does not need any file in this folder to run. To show a screenshot
in the main `README.md`, add a line such as:

```markdown
![Dashboard](assets/dashboard.png)
```
